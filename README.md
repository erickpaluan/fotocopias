# Paluan School

Projeto experimental da Paluan voltado à simplificação de processos operacionais em ambientes educacionais.

O projeto nasceu como uma ferramenta para organizar impressões universitárias e calcular custos de forma mais previsível. Essa implementação original funciona como ponto de partida para explorar outros problemas reais do contexto acadêmico.

## Origem

A primeira versão surgiu com um objetivo específico: facilitar a gestão de trabalhos de impressão em ambiente universitário.

Em vez de depender de cálculos manuais e informações dispersas, a aplicação centraliza dados necessários para estimar e organizar os serviços.

O projeto original era conhecido como **Fotocopias**.

## O que existe hoje

A implementação atual trabalha principalmente com:

- organização de trabalhos de impressão
- cálculo de custos
- interface web simples
- lógica de negócio em JavaScript
- persistência local de dados

## Direção do produto

O Paluan School não pretende ser apenas um sistema de impressão.

A ideia é utilizar o projeto como laboratório para identificar processos educacionais que ainda dependem de tarefas repetitivas, controles manuais ou ferramentas fragmentadas.

Possíveis evoluções serão definidas a partir de problemas concretos, não apenas pela adição de funcionalidades.

## Princípios

- resolver um problema real antes de aumentar o escopo
- manter a interface simples
- reduzir cálculos e tarefas repetitivas
- organizar informação de forma clara
- evoluir somente quando houver uma necessidade validada
